AISINGERS STUDIO — ЛОКАЛЬНАЯ ВЕРСИЯ ДЛЯ WINDOWS
=================================================

ПЕРВЫЙ ЗАПУСК

1. Убедитесь, что на диске свободно не менее 15 ГБ.
2. Желательно использовать видеокарту NVIDIA с актуальным драйвером.
3. Запустите файл «1_УСТАНОВИТЬ_AISingers.bat».
4. Дождитесь сообщения «ГОТОВО». Первая установка может быть долгой.
5. В дальнейшем запускайте «2_ЗАПУСТИТЬ_AISingers.bat».

Python заранее устанавливать не нужно. AISingers скачает собственный Python 3.12
и сохранит его внутри папки программы. Системный Python не изменяется.

КНОПКИ

1_УСТАНОВИТЬ_AISingers.bat
  Устанавливает локальный Python, библиотеки RVC, PyTorch и служебные модели.

2_ЗАПУСТИТЬ_AISingers.bat
  Запускает интерфейс и автоматически открывает его в браузере.

3_ОБНОВИТЬ_AISingers.bat
  Скачивает свежую версию с GitHub. Голосовые модели, аудио и настройки сохраняются.

4_ДИАГНОСТИКА_AISingers.bat
  Проверяет видеокарту, Python, CUDA и Gradio. Создаёт файл
  «AISingers_диагностика.txt», который можно отправить разработчику.

ВАЖНО

- Не переносите BAT-файлы отдельно от остальных папок проекта.
- Не удаляйте папки «.runtime» и «uv» после установки.
- Для работы загрузки моделей, TTS и YouTube требуется интернет.
- При первом запуске Windows может запросить разрешение на установку
  Microsoft Visual C++ Runtime — подтвердите его.
